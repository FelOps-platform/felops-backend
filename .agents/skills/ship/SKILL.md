Prepare the change for review by following the `pr-prep` skill.

1. For a substantive change, arrange a fresh `reviewer` (balanced tier; escalate only for demonstrated difficult issues, see [`.agents/README.md`](../../README.md#role-tiers)) before the PR text is final.
2. Push a branch, open or update a pull request, merge, or deploy only when the user has already authorized that action.

Do not claim checks, reviews, or external changes that were not completed.
