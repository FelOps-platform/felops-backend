# FelOps Backend

FelOps lets teams create AI agents that work inside their own workspace. Each agent is grounded in your knowledge (e.g., websites, documents, and text snippets), connected to your tools through workspace-level integrations, and deployed on the channels your customers already use (e.g., a website chat widget, a hosted chat page, or WhatsApp). Agents plan and carry out actions through an MCP server, with optional human approval for sensitive steps, and conversations can be handed over to a team member at any time.
