# Architecture decision records

Use an ADR for a decision that is difficult to reverse or materially affects architecture, data, security, dependencies, deployment, or an external contract.

Store one decision per sequentially numbered file:

docs/adr/ADR-0001-short-title.md

Start from docs/templates/ADR-template.md or use the adr-writer skill.

- Skip ADRs for routine, easily reversible choices.
- Do not renumber or delete an accepted ADR.
- Record a reversal in a new ADR and mark the prior decision Superseded.
