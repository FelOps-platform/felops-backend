Prepare the change for review.

1. Follow the pr-prep skill and fill .github/PULL_REQUEST_TEMPLATE.md.
2. Confirm the summary, linked issue when available, changed behavior, evidence, checks, documentation, risks, rollback, and checklist are accurate.
3. Check the final diff for unrelated files and secrets.
4. If arranging a reviewer for handoff, follow `docs/agent-routing.md` for its balanced default and evidence-based escalation; inherited-only roles cannot enforce the tier. Prepare the pull-request text. Push a branch, open or update a pull request, merge, or deploy only when the user has already authorized that action in the active instructions.

Do not claim checks, reviews, or external changes that were not completed.
